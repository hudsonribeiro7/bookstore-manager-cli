# BookStore Manager CLI

Sistema de gerenciamento de uma pequena livraria desenvolvido como projeto avaliativo do curso de Desenvolvimento de Sistemas.

## Objetivo

Desenvolver uma aplicação de linha de comando (CLI) para gerenciamento de:

- Autores
- Livros
- Clientes
- Empréstimos
- Devoluções
- Relatórios

A aplicação utiliza Node.js, TypeScript e PostgreSQL, seguindo uma arquitetura organizada em camadas.

## Tecnologias utilizadas

- Node.js
- TypeScript
- PostgreSQL
- pg
- dotenv
- tsx
- Git e GitHub

## Requisitos

Para executar o projeto é necessário ter instalado:

- Node.js
- PostgreSQL
- npm
- Git
